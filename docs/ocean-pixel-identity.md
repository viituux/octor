# Identidade visual do Octo

A interface utiliza a paleta clara solicitada: bg-app #f8fafc, bg-surface #ffffff, bg-sidebar #f1f5f9, border-color #e2e8f0, text-main #0f172a, text-muted #64748b, primary #0284c7 e primary-hover #0369a1.

O mascote foi removido: componente, arte, controles, eventos e espaço reservado. A marca textual Octo e as funcionalidades existentes permanecem.

Os tokens ficam em design-tokens.json. Executar node scripts/build-theme.cjs após alterá-los.
